# 能力分析与重点功能分析版式模板

> 本文件仅约束完整月度投产汇报中分析模块的**标题结构与版式**。  
> 正文要点由当次接口清单归纳生成，禁止照搬历史截图文案。  
> 触发条件、意图档位以 `SKILL.md`「意图识别总表」为准。  
> 产品线分类以 `SKILL.md`「产品线分类标准」为准（链数 → 云链证 → 云信 → 链信APP → 信企直连 → 基础服务 → 其他）。

适用场景：意图 E / F / G，或用户点名能力分析 / 重点功能分析时，在量化明细之后输出分析。

输出通则：**先列明细，再列分析。**

| 查询范围 | 对应意图 | 输出模块 |
|----------|----------|----------|
| 仅查询上月（含「上月已上线情况」） | E | 「上个月两项能力分析」：业务场景能力提升、基础服务能力夯实 |
| 仅查询本月 | F | 仅「重点功能分析」 |
| 同时涉及上月以及本月 | G | 「上个月两项能力分析」+「重点功能分析」 |
| 指定历史月「X 月已上线情况/汇总」 | 类 E | 业务场景能力提升、基础服务能力夯实（数据源=该月清单） |
| 仅点名能力分析 / 业务场景 / 基础服务夯实 | 专项→E | 能力分析两项（缺省月=上月） |
| 仅点名重点功能分析 | 专项→F | 重点功能分析（缺省月=本月） |

**打开分析信号词**：情况、汇总、汇报、总结、盘点、整体、全面、完整、能力分析、重点功能分析。  
**不打开**：纯多少/数量/分布；纯清单/列表/明细；纯待投产。

数据约定：

| 模块 | 数据来源 | 何时输出 |
|------|----------|----------|
| 上个月两项能力分析 | 上月 / 指定历史月已上线清单；意图 G 时为 `prevMonth` | 意图 E、G，专项能力分析，或指定月已上线情况/汇总 |
| 重点功能分析 | 查询月拟上线清单 | 意图 F、G，或专项重点功能分析 |
