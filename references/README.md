# references 目录说明

该目录用于存放投产情况汇报模块的操作手册或补充说明文档。

## 手册文件

- `production-summary-manual.md`：投产情况汇报模块使用手册（流程、字段说明、常见问题）
- `capability-analysis-template.md`：月度完整汇报中「上个月两项能力分析」「重点功能分析」的版式模板（正文由接口清单归纳，非静态文案）

## 建议章节结构

每份手册建议包含以下章节，便于快速问答：

1. 功能概述
2. 角色与权限
3. 操作入口
4. 标准操作步骤
5. 状态流转规则
6. 字段说明
7. 常见异常与处理
8. 术语说明

## 版本管理建议

- 文件顶部增加 `版本号 / 更新日期 / 维护人`
- 若规则变更，保留"变更记录"小节
