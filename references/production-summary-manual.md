## 1. 功能概述

研发中心项目投产情况汇报页面，用于按月查看研发中心项目的投产全貌，包括：

- **已上线项目**：当月已完成投产的项目数量、功能项数及详细清单。
- **计划上线项目**：下个月计划投产的项目数量、拟上线清单。
- **待投产需求点**：尚未投产的需求点汇总，按产品线分组展示。
- **能力分析与重点功能分析**（完整月度汇报）：出数后基于接口清单归纳输出；**先列明细，再列分析**。按查询范围区分：
  - **仅查询本月**：只输出「重点功能分析」（基于查询月拟上线清单，归纳「业务重点功能分析」「基础服务重点功能分析」）；不输出上个月两项能力分析。
  - **同时涉及上月以及本月**：输出全部分析——「上个月两项能力分析」（基于 `prevMonth` 已上线清单，归纳「业务场景能力提升」「基础服务能力夯实」）+「重点功能分析」。
  - 版式见 `capability-analysis-template.md`；正文须可追溯到清单，禁止无依据编造。

入口：`http://yunqing.test.yljr.com/RD/productionSummary.htm`（测试）

## 3. 操作入口

1. 登录研发效能平台。
2. 导航至「项目投产情况汇报」标签页。
3. 通过顶部月份选择器切换查询月份，点击「查询」按钮刷新数据。

## 4. 页面区块说明

### 4.1 已上线项目区块

| 字段 | 说明 |
|------|------|
| 上线项目数 / 功能项数 | 当月已完成投产的项目总数与对应功能项总数 |
| 排期项目数（按上线窗口） | 按上线窗口类型（常规、临时、紧急）分类的项目数统计 |
| 上线项目窗口分布图 | 各上线日期的项目数量柱状图 |
| 功能点产品线分布图 | 各产品线功能点数量分布饼图 |
| 上线清单 | 已上线项目详情表格（见下方字段说明） |

**上线清单字段说明：**

| 字段 | 含义 |
|------|------|
| 序号 | 列表序号 |
| 项目编号 | Jira 项目编号（`jiraNo`） |
| 项目名称 | 项目全称（`projectName`） |
| 产品线 | 所属产品线（`productLine`） |
| 键值 | 项目键值标识（`keyValue`） |
| 项目描述 | 项目功能简述（`description`） |
| 上线窗口类型 | 常规 / 临时 / 紧急（`windowType`） |
| 上线日期 | 实际上线日期（`onlineDate`，时间戳） |

### 4.2 计划上线项目区块

| 字段 | 说明 |
|------|------|
| 计划上线项目数 / 功能项数 | 计划投产的项目总数与功能项总数 |
| 排期项目数（按上线窗口） | 同上，针对计划月份 |
| 拟上线清单 | 拟上线项目详情表格（见下方字段说明） |

**拟上线清单字段说明：**

| 字段 | 含义 |
|------|------|
| 产品线 | 所属产品线（`productLine`） |
| 项目编号 | Jira 项目编号（`jiraId`） |
| 项目名称 | 项目全称（`projectName`） |
| 键值 | 项目键值标识（`keyValue`） |
| 项目描述 | 项目功能简述（`description`） |
| 排期类型 | 常规 / 临时 / 紧急（`topLineType`） |
| 计划上线日期 | 计划上线日期（`onlineDate`） |

### 4.3 待投产需求点区块

按产品线分组展示尚未投产的需求点。

| 字段 | 含义 |
|------|------|
| 编号 | Jira 项目编号（`jiraNo`） |
| 项目名称 | 项目全称（`projectName`） |
| 产品线 | 所属产品线（`productLine`） |
| 项目描述 | 需求功能说明（`description`） |
| 计划上线日期 | 预计投产日期（`planOnlineTime`，时间戳） |
| 需求来源部门 | 提出该需求的业务部门（`sourceDept`） |

## 6. 常见异常与处理

| 现象 | 可能原因 | 处理建议 |
|------|----------|----------|
| 数据显示 0 / 0 | 当月尚无排期数据 | 确认月份选择是否正确 |
| 暂无排期数据 | 上线窗口未录入 | 联系排期负责人确认 |
| 接口超时 | 网络问题或服务未启动 | 检查内网连接，确认服务状态 |

## 7. 术语说明

| 术语 | 含义 |
|------|------|
| 上线窗口 | 项目允许发布到生产的时间窗口，分为常规、临时、紧急三类 |
| 产品线 | 产品业务归属分类，如云链证、云链贷等 |
| 功能项数 | 一个项目包含的功能点数量 |
| 待投产需求点 | 已进入排期但尚未完成上线的需求条目 |
| 拟上线清单 | 计划上线月份的拟上线项目列表 |
| 业务场景能力提升 | 同时涉及上月以及本月时，对上月已上线业务产品能力的归纳小结 |
| 基础服务能力夯实 | 同时涉及上月以及本月时，对上月已上线资金端/中台/平台等基础能力的归纳小结 |
| 业务重点功能分析 | 完整汇报中对当月拟上线业务重点功能的归纳小结（仅查本月时亦输出） |
| 基础服务重点功能分析 | 完整汇报中对当月拟上线基础服务重点功能的归纳小结（仅查本月时亦输出） |
